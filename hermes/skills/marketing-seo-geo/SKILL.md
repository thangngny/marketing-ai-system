# Marketing SEO GEO Skill

Plan organic search and generative-engine visibility with measurable hypotheses. It does not promise rankings or fabricate volume data.

## When to Use

Use for keyword maps, technical/content briefs, competitor visibility, and AI-search citations.

## Prerequisites

Use `marketing_handle_request` and current evidence from `web_search`/`web_extract` when research is requested.

## How to Run

Map business intent to search intent and a canonical page.

## Quick Reference

Label estimated volume/difficulty as estimates unless a connected data source supplied them.

## Procedure

1. Cluster queries by intent.
2. Map one primary page per cluster.
3. Identify evidence, entity, and internal-link needs.
4. Add technical checks and measurement.
5. Propose an update cadence.

## Pitfalls

Do not confuse keyword presence with business conversion.

## Verification

The plan links queries, pages, proof, CTA, and measurable outcomes.
