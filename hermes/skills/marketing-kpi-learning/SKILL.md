# Marketing KPI Learning Skill

Turn operational metrics into decisions and experiments. It does not invent missing data or infer causality from correlation alone.

## When to Use

Use for weekly reports, attribution, funnel leakage, experiment reviews, and recommendations.

## Prerequisites

Use `marketing_handle_request`; query only connectors that report the required read capability.

## How to Run

Confirm period, source, metric definition, baseline, and target.

## Quick Reference

Compare target, prior period, and baseline; report missing data.

## Procedure

1. Validate metric definitions and sources.
2. Analyze reach→lead→MQL→SQL→meeting→opportunity→revenue.
3. Identify anomalies and delays.
4. Separate correlation from causal evidence.
5. Produce an experiment backlog with decision thresholds.

## Pitfalls

Do not recommend higher spend from vanity metrics alone.

## Verification

The report contains sources, scorecard, leakage, learning, decision, and next test.
