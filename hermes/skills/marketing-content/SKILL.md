# Marketing Content Skill

Create concrete copy and briefs that fit the audience, funnel stage, and channel. All output remains a draft until a person approves publication.

## When to Use

Use for LinkedIn, website, email, YouTube, Facebook, TikTok, landing pages, and sales assets.

## Prerequisites

Use `marketing_handle_request`; read approved company/brand context with `read_file`.

## How to Run

Identify audience, objective, channel, proof, and CTA.

## Quick Reference

Label the output `DRAFT — CHƯA ĐĂNG`.

## Procedure

1. Select an angle tied to an ICP pain.
2. Draft channel-native content.
3. Check claims and placeholders.
4. Add CTA and review checklist.

## Pitfalls

Do not invent case studies, testimonials, certifications, prices, or performance claims.

## Verification

The result is usable copy and explicitly states that no publication occurred.
